# スマホ実機確認チェックリスト（Ver.0.2）

iPhone（Safari）と Android（Chrome）でそれぞれ確認する。できれば小さい画面（iPhone SE など）も1台含める。
結果は「OK / NG（状況）」で記入する。

## 準備

- 同じ Wi-Fi のスマホから開発機にアクセスする：`python3 tools/serve.py` を起動し、`http://<開発機のIPアドレス>:8000/` を開く
- または GitHub Pages に公開したURLで確認する

## 入力（最重要）

| # | 確認内容 | iPhone | Android |
|---|---|---|---|
| 1 | かな入力の変換中（下線がある状態）に Enter／改行を押しても送信されない | | |
| 2 | 変換を確定した直後の Enter で誤って送信されない（確定と送信が1回の操作で起きない） | | |
| 3 | 変換確定後にもう一度 Enter／「回答する」で送信できる | | |
| 4 | 「ー」を入力できる（長音キー）。「〜」や「-」になってしまわないか | | |
| 5 | 小さい文字（ゃ・ゅ・ょ・っ・ぁ）を入力できる（例：きゃべつ、がっこう） | | |
| 6 | カタカナに変換して送信しても正しく判定される（例：コーヒー） | | |
| 7 | 入力欄が空のとき「回答する」が押せない | | |
| 8 | 「回答する」を押したあとは入力欄が変更できず、ボタンが「回答済み ✓」になる | | |
| 9 | 入力欄をタップしても画面が勝手に拡大されない | | |

## フレンド対戦（Ver.0.2）

2台の端末（できれば iPhone と Android）で、公開URLを開いて確認する。2台の欄には「ホスト / ゲスト」の結果を書く。
回線は、最初は両方 Wi-Fi、次に片方をモバイル回線（Wi-Fi を切る）にして、もう一度通して確認する。

| # | 確認内容 | ホスト | ゲスト |
|---|---|---|---|
| F1 | タイトルに「フレンド対戦」が出て、開くと「接続中…」のあとロビーが表示される | | |
| F2 | 名前を入れて「部屋を作る」を押すと、6桁の部屋コードが出る | | |
| F3 | 部屋コードの入力欄をタップすると数字キーボードが出る。6桁を入れて「参加する」で参加できる | | |
| F4 | 間違ったコード（5桁・存在しない番号）では参加できず、分かるメッセージが出る | | |
| F5 | 参加すると、両方の画面に相手の名前が出る | | |
| F6 | 両者が「準備OK」を押すと対戦が始まる。片方だけでは始まらない。「準備OKを取り消す」で取り消せる | | |
| F7 | ROUND / READY / FIGHT! が2台でほぼ同時に出る（ずれが気にならない） | | |
| F8 | READY まではお題が「？」で、FIGHT! と同時に2台で同じお題が出る | | |
| F9 | FIGHT! 後に入力欄をタップしてすぐ入力・送信できる（iOS はタップでキーボードが開くか） | | |
| F10 | 相手が回答すると「回答済み ✓」が出る。相手の言葉は判定タイムまで見えない | | |
| F11 | 判定タイムの結果（両者の言葉・文字数・秒数・有効/無効・ダメージ）と HP が2台で一致する | | |
| F12 | 判定タイムの3秒後に、2台そろって次の ROUND へ進む（スキップや待たされることがない） | | |
| F13 | 決着後、両方の結果画面が正しい（片方が勝ち、片方が負け／引き分けなら両方引き分け） | | |
| F14 | 戦績画面の「フレンド戦」に記録され、「CPU戦」の戦績は変わらない。レートも変わらない | | |
| F15 | 対戦中に片方が再読み込みすると、相手に「接続待ち」が出て、同じ対戦に戻れる（ホスト・ゲストの両方で試す） | | |
| F16 | 対戦中に片方がアプリを閉じる（またはタブを閉じる・機内モード）と、相手に「接続待ち」が出て、約20秒で試合中止になる。勝敗は記録されない | | |
| F17 | 対戦中にアプリを切り替えて数秒で戻ったとき、対戦が続く（または接続待ちから復帰する） | | |
| F18 | 片方が「やめる」を押すと、押した側が負け・相手が勝ちとして両方に表示・記録される（ホスト・ゲストの両方で試す） | | |
| F19 | Wi-Fi とモバイル回線の混在でも、F7・F11・F12 のずれや遅れが気にならない | | |
| F20 | ロビーで「部屋を出る」を押したとき：ホストなら部屋が閉じてゲストに通知が出る／ゲストなら部屋から抜ける | | |
