# スマホ実機確認チェックリスト（Ver.0.1）

iPhone（Safari）と Android（Chrome）でそれぞれ確認する。できれば小さい画面（iPhone SE など）も1台含める。
結果は「OK / NG（状況）」で記入する。

## 準備

- 同じ Wi-Fi のスマホから開発機にアクセスする：`python3 tools/serve.py` を起動し、`http://<開発機のIPアドレス>:8000/` を開く
- または GitHub Pages に公開したURLで確認する

## 入力（最重要）

| # | 確認内容 | iPhone | Android |
|---|---|---|---|
| 1 | かな入力の変換中（下線がある状態）に Enter／改行を押しても送信されない | | |
| 2 | 変換を確定した直後の Enter で誤って送信されない（確定と送信が1回の操作で起きない） | | |
| 3 | 変換確定後にもう一度 Enter／「回答する」で送信できる | | |
| 4 | 「ー」を入力できる（長音キー）。「〜」や「-」になってしまわないか | | |
| 5 | 小さい文字（ゃ・ゅ・ょ・っ・ぁ）を入力できる（例：きゃべつ、がっこう） | | |
| 6 | カタカナに変換して送信しても正しく判定される（例：コーヒー） | | |
| 7 | 入力欄が空のとき「回答する」が押せない | | |
| 8 | 「回答する」を押したあとは入力欄が変更できず、ボタンが「回答済み ✓」になる | | |
| 9 | 入力欄をタップしても画面が勝手に拡大されない | | |
